    What this service does

    A send-only WhatsApp gateway. Authenticated callers POST a recipient and a message body — the service queues it, delivers it via WhatsApp, and retries automatically on failure. This number is dedicated exclusively to outbound messaging.

    Authentication

    Every send request must include a Bearer token in the Authorization header. Create tokens in the Tokens tab — one token per calling service is the recommended pattern.

    Authorization: Bearer <your-token>

    Phone number format

    The to field expects E.164 international format with no + sign and no separators — just the country code followed by the subscriber number. Drop any leading 0 from the local format before prepending the country code.

    CountryLocal formatSend as to
    Israel (+972)050-123-4567 / 0501234567972501234567
    USA (+1)(415) 555-012314155550123
    UK (+44)07911 123456447911123456
    Germany (+49)0151 123456784915112345678

    Common mistakes: a leading +, a leading 0 kept after adding country code, hyphens or spaces, or local-format-only digits without country code — all will fail.

    Note on first sends to a number: WhatsApp requires a one-time identity lookup (usync) for any number not yet seen by this account. If the recipient has never been messaged from this WhatsApp account before, the first send may time out — open a brief chat with them from the linked phone (so the contact syncs), then retry.

    Endpoints

    POST /api/send Send a WhatsApp message

    Queues a message for delivery. Returns immediately — delivery happens asynchronously with automatic retry.

    Request body (JSON)
    {
  "to":   "972501234567",   // phone number (international format, no +)
  "body": "Hello from the bot"
}
    Success response 202
    {
  "id":     42,          // message ID — use to track in the Messages tab
  "status": "queued"
}
    curl
    curl -X POST __HOST__/api/send \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"to":"972501234567","body":"Hello"}'
    Python
    import requests

r = requests.post(
    "__HOST__/api/send",
    headers={"Authorization": "Bearer <token>"},
    json={"to": "972501234567", "body": "Hello"},
)
print(r.json())  # {"id": 42, "status": "queued"}
    Node.js / fetch
    const res = await fetch("__HOST__/api/send", {
  method: "POST",
  headers: {
    "Authorization": "Bearer <token>",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({ to: "972501234567", body: "Hello" }),
});
const { id, status } = await res.json();
    GET /api/status WhatsApp connection state

    Returns whether the service is connected to WhatsApp. Messages sent while disconnected are queued and delivered automatically once reconnected.

    {
  "connected": true,
  "phone": "972501234567"   // or null if not connected
}
    GET /api/health Liveness check 
    { "ok": true }

    GET /api/events Server-Sent Events stream

    Subscribe to live connection and message status changes. Use this to avoid polling /api/status or /api/messages in hot loops.

    Events emitted
    event: status            // WA connection state changed
data: {"connected":true,"phone":"972501234567"}

event: connection_lost
data: {"at":1745666000000}

event: connection_restored
data: {"phone":"972501234567","at":1745666060000}

event: message_update    // delivery status changed
data: {"id":42,"status":"sent"}
    JavaScript
    const es = new EventSource("__HOST__/api/events");
es.addEventListener("connection_lost", () => console.warn("WA disconnected"));
es.addEventListener("message_update", (e) => {
  const { id, status } = JSON.parse(e.data);
  console.log(`message ${id} → ${status}`);
});

    Message lifecycle

    Every message moves through these states:

    pending → sending → sent
    On failure: retried up to 3× with exponential backoff (30 s → 60 s → 120 s), then failed

    Messages queued while WhatsApp is disconnected will be delivered automatically once the connection is restored.

    Phone number format

    Pass the international number without a leading + and without spaces or dashes. wacli resolves the WhatsApp JID automatically.

    ✓  972501234567
✓  14155552671
✗  +972-50-123-4567
✗  050-123-4567
